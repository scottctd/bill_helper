# API Topic Map

Use this directory when the top-level API index is still too broad.

## Files

- `core_ledger.md`: accounts, snapshots, reconciliation, entries, groups, filter groups, and dashboard.
- `catalogs_and_settings.md`: auth, admin, users, entities, tags, taxonomies, currencies, and runtime settings.
- `agent.md`: agent sessions, session sources, threads, thread-scoped proposals, messages, runs, tool calls, change-item review, and attachments.
- `import_workflow.md`: import preflight, jobs, task progress, and aggregated proposal review.
- `workspace.md`: legacy opt-in per-user sandbox lifecycle and current file-tree reads.

## Fastest Path By Question

- "How do ledger and graph endpoints behave?" -> `core_ledger.md`
- "How do login, admin, catalog, or settings endpoints behave?" -> `catalogs_and_settings.md`
- "How does the agent API stream, review, attach sources, or interrupt work?" -> `agent.md`
- "How does the import job API work?" -> `import_workflow.md`
- "How do I inspect or start the legacy workspace?" -> `workspace.md`
