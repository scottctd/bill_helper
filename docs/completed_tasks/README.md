# Completed Task Archive

This directory is the single archive for finished implementation task docs.

- Use dated filenames in the form `YYYY_MM_DD-task_name.md`.
- Keep durable behavior and architecture details in the canonical docs under `docs/`, `backend/docs/`, `frontend/docs/`, and `docs/features/`.
- Treat files here as historical context, not source-of-truth for current behavior.

## Layout

- `tasks/*.md`: active implementation plans, migration notes, and temporary caveats.
- `docs/completed_tasks/*.md`: archived tasks, retrospectives, and fix logs after work lands.

The legacy `tasks/completed/` directory was consolidated here in 2026-07.
